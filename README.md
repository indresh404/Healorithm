# 🏥 Rural Healthcare Ecosystem (Offline-First Health Platform)

## 📌 Description

An **offline-first, QR-based rural healthcare platform** that connects patients, field workers, and health authorities to enable continuous medical care, real-time monitoring, and AI-driven health insights even in low-connectivity areas.

---

## 🚀 Features

### 👨‍🌾 Patient App
- QR-based digital health identity  
- Offline medical record storage  
- Voice-based multilingual interface  
- Medicine & visit reminders (offline)  
- Emergency SOS alerts  
- AI-based symptom guidance (rule-based)  
- Nearby healthcare access (cached)  

---

### 👩‍⚕️ Field Worker App
- QR scan for instant patient access  
- Offline data entry (symptoms, vitals, prescriptions)  
- Bluetooth IoT vitals integration (BP, SpO2)  
- Emergency detection system  
- Smart patient prioritization  
- Automatic sync engine  

---

### 🏛️ Admin Dashboard
- AI-based patient risk scoring (0–100)  
- Disease outbreak detection (DBSCAN clustering)  
- Village-level health heatmaps  
- Trend analysis & reporting  
- Worker monitoring system  

---

### ⚙️ System Features
- Offline-first architecture  
- QR-based patient identity system  
- Automatic background sync engine  
- Role-based access (Patient / Worker / Admin)  
- Secure JWT authentication  
- Encrypted local storage
